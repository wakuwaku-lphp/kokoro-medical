## 公開後にやること
1. `index.html` / `robots.txt` / `sitemap.xml` 内の `SITE_URL` を公開URLに一括置換（例: `kokoro-medi.github.io`、独自ドメインならそのドメイン）
2. Google Search Console に登録し、sitemap.xml を送信
3. Googleビジネスプロフィールのウェブサイト欄にこのURLを設定（NAPは「心メディカル整体院 / 〒372-0818 群馬県伊勢崎市連取元町240-1 / 0270-50-0889」で統一）
